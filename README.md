# Oposiciones

PWA para estudiar oposiciones jugando: responde preguntas tipo test, gana monedas, y (próximamente) compra mascotas que crecen, herramientas y decoración para tu casa. Tema inicial: Constitución Española.

- Se instala en el móvil (Android/iOS) desde el navegador, sin tiendas de aplicaciones: «Añadir a pantalla de inicio» / «Instalar aplicación».
- Funciona sin conexión. Los datos (monedas, progreso) viven solo en tu dispositivo; Ajustes permite exportar e importar una copia.
- Sin dependencias ni build: JS plano. `npm test` · `node serve.mjs` (puerto 8097).

Las preguntas son de redacción propia a partir del texto oficial de la Constitución (BOE); el banco actual es una muestra pendiente de revisión.

Documentación: `CLAUDE.md`, `docs/`.
